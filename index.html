给 Canvas 2D 的孔版印刷网点引擎 —— 源码与文档在 GitHub

  • 网点角度：三墨两两相差 30°(mod 90)，按相对亮度分配（最暗 45° / 中 75° / 最亮 15°）
  • 连续色阶：r = cell·√(t/π)，60 档，t>0.5 翻转成挖白点
  • 逐帧 boil：三版轮换 3Hz。半径流不带 variant —— 位置变化读成"工艺"，密度变化读成"闪"
